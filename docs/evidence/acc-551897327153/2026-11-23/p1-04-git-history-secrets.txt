# P1-04 Rò rỉ secret trong lịch sử git (repo PUBLIC Elmira-Athena/PBL3) — 2026-11-23

PHÁT HIỆN F12 (High→xác minh): một cặp AWS access key (IAM user, tiền tố AKIAV6CS…, secret
đi kèm) từng được commit trong `src/API/appsettings.Development.json`, thêm ở commit 5c88b20
(2026-05-12) và gỡ khỏi HEAD cùng ngày (b873c7e, 5a67b4e "Untrack … already gitignored").
Vì repo PUBLIC, "gỡ ở HEAD" KHÔNG xoá khỏi lịch sử — vẫn `git show 5c88b20` đọc được.

Đối chiếu account 551897327153: hai access key đang Active là của user `hushstore-ops` (…4MGM)
và `test` (…XBXG). Key bị lộ (…CPB4) KHÔNG nằm trong số đó ⇒ nhiều khả năng đã bị xoá/vô hiệu.
KHÔNG thử dùng key để xác minh (dùng credential nhặt được là ngoài phạm vi pentest).

Chuỗi khác trong lịch sử (đã che):
- `Infrastructure/db/.env` (7133aaa, 1a09df8): SA_PASSWORD của SQL Server local (đợt trước Postgres).
- workflow OIDC 8f12a58: chỉ là lệnh `aws configure set … "$AWS_SECRET_ACCESS_KEY"` đọc từ biến CI,
  không phải giá trị thật.
- Các Password= còn lại là connection string mẫu/design-time (localhost, placeholder).

KHUYẾN NGHỊ:
1. Vào IAM xác nhận key …CPB4 đã bị xoá; nếu còn thì vô hiệu + xoay ngay.
2. Coi SA_PASSWORD và mọi secret từng commit là đã lộ → xoay.
3. Repo đồ án: cân nhắc chuyển private, hoặc rewrite lịch sử (git filter-repo) nếu cần giữ public.
